## Why these aren't pre-filled

Screenshots of a certificate or a live repository are evidence that something actually happened — the course was completed, the project was configured, the repo was pushed. Generating fake versions of these would misrepresent your actual progress, so this is the one part of the submission that has to come from you directly. Everything else in this repository (report, notes, spreadsheet, task breakdown) is ready to submit as-is.

**Quick capture tips:**
- Use a clean browser window (close unrelated tabs) before capturing.
- PNG format, cropped to the relevant panel — no need to capture the whole screen.
- Keep filenames exactly as listed above so the references in `README.md` and the report stay accurate.
