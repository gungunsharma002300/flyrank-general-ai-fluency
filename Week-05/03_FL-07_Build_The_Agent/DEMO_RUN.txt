# Computer Networks — Unit 1 Demo Notes

## OSI Model
The OSI model is a seven-layer reference model for network communication.
The seven layers are Application, Presentation, Session, Transport, Network,
Data Link, and Physical.

## Network Goals
Computer networks support resource sharing, communication, data sharing,
remote access, reliability, cost reduction, and scalability.

## Protocol
A protocol is a set of rules that controls communication between devices.
Examples include TCP, IP, HTTP, FTP, and SMTP.

## Network Categories
PAN covers a very small area around an individual.
LAN covers a local area such as a building or campus.
MAN covers a metropolitan area.
WAN covers a large geographical area.
