# FlyRank PF-04 — Personal Website

## Purpose
A one-page personal portfolio for Gungun Sharma, built with plain HTML, CSS and JavaScript and designed for free static hosting such as Netlify.

## Files to understand
- `site/index.html` — page structure, content and navigation.
- `site/style.css` — all visual styling and responsive layout.
- `site/script.js` — tiny enhancement for navigation state; the site does not depend on JavaScript for core content.
- `site/booking.html` — public connect/booking-style page.
- `site/resume.html` — web CV page.
- `site/Gungun_Sharma_CV.pdf` — downloadable CV.
- `docs/DNS_WALKTHROUGH.md` — PF-04 DNS deliverable.
- `docs/NETLIFY_DEPLOYMENT.md` — deployment checklist.

## Public links included

## Important
The assignment's live HTTPS URL cannot be truthfully pre-created from this ZIP because deployment must happen in the student's Netlify account. After deployment, rename the Netlify site to a CV-friendly name and submit that live URL.

Do not claim a URL is live until it has been opened in a private/incognito window.
