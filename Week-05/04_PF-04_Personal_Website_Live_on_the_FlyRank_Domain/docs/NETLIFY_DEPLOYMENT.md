# PF-04 Netlify Deployment — exact steps

1. Extract this ZIP.
2. Open Netlify Drop: https://app.netlify.com/drop
3. Drag the **`site` folder** onto the drop area.
4. Wait for Netlify to publish the site and copy the HTTPS URL.
5. In Netlify, open Site configuration → Change site name.
6. Choose a CV-friendly available name such as `gungun-sharma` or another available variation.
7. Open the renamed HTTPS URL in an incognito/private browser window.
8. Test:
   - navigation links
   - LinkedIn
   - GitHub
   - CV PDF
   - Book / connect page
9. If everything works, submit the public HTTPS URL under **Deliverable links**.
10. Upload `docs/DNS_WALKTHROUGH.md` (or convert it to PDF if preferred) under **Files**.
