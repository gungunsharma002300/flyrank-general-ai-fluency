# Deployment

## Vercel
1. Put this folder in a GitHub repository.
2. Open Vercel and import the repository.
3. Keep the framework preset as **Other** (or Static).
4. Build command: leave empty.
5. Output directory: leave empty / root.
6. Deploy.
7. Open the live URL and test the contact form.

## Important
Do not claim the assignment is fully tested until you have made a real test submission from the deployed website and verified it in Formspree.
