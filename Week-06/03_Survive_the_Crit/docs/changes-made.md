# Changes Made

## Must-fix 1 — Descriptive → demonstrative

Added proof-oriented project cards with concrete evidence fields instead of only paragraphs.

## Must-fix 2 — Verification

Added direct GitHub and live-site links for the portfolio where the public destinations are known.

## Must-fix 3 — Project status

Projects now use explicit status labels:
- COMPLETED ANALYSIS
- LIVE
- IN PROGRESS

## Must-fix 4 — Consistent project format

Each project follows:
1. Problem / Goal
2. What I built
3. Technologies / Areas
4. Result / Evidence
5. Links where available

## Must-fix 5 — Genuine measurable evidence

The Zomato project includes the documented figures available in the project evidence:
- 105 restaurants
- 9,954 reviews
- 63% positive sentiment
- Random Forest classification reported 100% accuracy in the analysis

No invented performance metric has been added to the portfolio.

## Accessibility/mobile improvements

- Keyboard-visible focus states
- Skip-to-content link
- Semantic navigation
- Mobile menu with `aria-expanded` and `aria-controls`
- Responsive layout
- `prefers-reduced-motion` support
- No horizontal overflow on narrow screens
