# Reviewer Feedback

## Reviewer

A real peer/friend reviewed the live portfolio through WhatsApp.

## Required 10-second questions

### 1. In ten seconds, what do I do?

The reviewer understood that I am a BCA student building toward a career in Data Analytics, with hands-on work in Python, SQL, AI/ML and related projects. The reviewer specifically said the hero communicates “Data, Python & AI” quickly.

### 2. Would you believe I’m good at it?

The reviewer said yes, but wanted stronger proof before being fully convinced.

## Main feedback

- The portfolio looks professional.
- The projects are relevant.
- The structure/navigation is decent.
- The biggest weakness is that much of the evidence is descriptive rather than demonstrative.
- The portfolio should show more screenshots, GitHub links, live demos or other concrete proof.
- Measurable outcomes should be added where they are genuinely available.
- Repositories should be easy to verify.
- Working demos should be deployed where available.
- In-progress projects should be clearly marked so they are not mistaken for finished work.
- A consistent project format would help: Problem → What I built → Technologies → Result → GitHub/Demo.
