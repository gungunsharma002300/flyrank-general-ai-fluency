# Week 7 — Findability & SEO

## Implemented
- Descriptive page titles on all public pages.
- Meta descriptions on all public pages.
- Canonical URLs.
- Open Graph title/description/URL/image metadata.
- Twitter Card metadata.
- `robots.txt`.
- `sitemap.xml`.
- Lightweight SVG social-preview image.
- Semantic headings and readable page structure.

## Search check
The site should be searched by the exact name and by the production URL after the latest deployment. Search engines may take time to index a newly deployed site, so the absence of a result is recorded as an observation rather than presented as a defect.

## Speed check
Run the production URL through Google PageSpeed Insights and attach the result screenshot to the Week 7 evidence folder. No score is invented in this repository.
