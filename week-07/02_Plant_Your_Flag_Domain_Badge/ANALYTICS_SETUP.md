# Vercel Web Analytics — final activation

The HTML already contains the Vercel Analytics script tag. Vercel provides Web Analytics for websites using a script tag.

### Do this after deploying
1. Open the Vercel project.
2. Open **Analytics** / **Web Analytics**.
3. Enable Web Analytics if prompted.
4. Open the live portfolio in a new tab and refresh once.
5. Return to Analytics and capture the real visit/page-view evidence.

Do not create a fake analytics screenshot.
