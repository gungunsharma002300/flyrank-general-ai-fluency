# FlyRank Graduate Badge

The assignment requires the actual FlyRank graduate badge in the footer and a link to the account-specific verification page.

The site currently links the footer badge text to the official badge service supplied by the assignment:
`https://internship-badge.netlify.app/`

### Final manual step
Open the badge service, obtain the graduate badge/verification URL assigned to your account, then replace the footer href in `site/index.html` with that exact verification URL and add the issued badge image if the service provides one.

This step is intentionally not fabricated because the verification URL is account-specific.
