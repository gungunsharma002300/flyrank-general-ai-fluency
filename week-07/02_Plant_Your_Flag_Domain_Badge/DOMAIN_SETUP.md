# Domain setup

### Zero-budget fallback
Use the existing Vercel production URL:
`https://flyrank-general-ai-fluency.vercel.app/`

This is already a public HTTPS production URL.

### Custom domain (optional)
If you own a domain, use Vercel **Project Settings → Domains → Add Domain** and follow the DNS instructions Vercel provides. Do not invent DNS records; copy the records shown by Vercel for the specific domain.
