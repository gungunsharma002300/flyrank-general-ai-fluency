# Week 7 — Plant Your Flag: Domain + Badge

## Requirement mapping
1. **Domain:** The assignment allows a clean free subdomain when budget is zero. The portfolio is deployed on the Vercel production domain: `https://flyrank-general-ai-fluency.vercel.app/`. A custom domain can be connected later without changing the site files. Vercel documents adding a custom domain from Project Settings → Domains.
2. **Analytics:** Vercel Web Analytics script is included on the site. After deployment, enable Web Analytics in the Vercel project and verify a visit appears in Analytics.
3. **Launch hygiene:** Added page descriptions, canonical URL, Open Graph/Twitter metadata, favicon, robots.txt and sitemap.xml.
4. **Graduate badge:** Footer contains a link to the FlyRank internship badge service. The final account-specific verification URL must be inserted after the issued badge/verification page is obtained.
